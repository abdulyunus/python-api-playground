# My First Application

This is a simple Python application built using FlaskOpenAPI3 and Pydantic. It provides an API endpoint to retrieve book details based on query parameters.

## Features

- **OpenAPI Integration**: Automatically generates OpenAPI documentation for the API.
- **Book API**: A single endpoint to fetch book details using query parameters.
- **Pydantic Models**: Ensures data validation for query parameters.
